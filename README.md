# LLD

This project contains Low-Level Design (LLD) implementations of certain systems. Each project also has an **`HLD.md`** for the interview whiteboard view (architecture diagram, tech tradeoffs, components, discussion points).

## What’s in each `HLD.md`

1. **Final architecture diagram** (mermaid)
2. **Why this tech / why not competitors**
3. **Each component** — ownership & interview notes
4. **Other interview discussion points** — clarify questions, hot topics, scale, follow-ups
